# figures/

This directory holds two separate figure sources.

## notebook_figures/

Figures automatically generated by `notebooks/06_plots.ipynb` and
`notebooks/07_paper_visuals.ipynb` are written here. `src/io.py:get_figure_dir()`
returns this path; when `TEST_MODE=1` the output is isolated under
`.artifacts/smoke/figures/notebook_figures/`. Historical paper versions may
include figures from this directory, and its preserved outputs provide the
parity references for standalone historical figure ports.

## script_figures/

Manually produced figures are stored here; they are independent of the notebook
pipeline.

The active `paper/03-07-2026-1550-edition/` manuscript uses this directory. Its
three `07_fig*` scripts generate the dataset-construction figure, the current
rater-dominance schematic, and the canonical Gemma rescue panels without a
notebook execution step. Preserved notebook outputs remain historical references,
not parity requirements for the two figures intentionally updated since then.

Each figure must exist as **three files** sharing the same name:

```
figures/script_figures/
    <name>.png       ← raster output
    <name>.pdf       ← vector output
    <name>.py        ← generating script (use the matching extension for other languages)
```

The figure and the code that produces it always share the same basename and sit
side by side. This rule is also defined in the HARD RULE section of `AGENTS.md`.
