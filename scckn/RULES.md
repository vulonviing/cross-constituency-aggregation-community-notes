# Usage Rules

## Quotas and Limits

| Resource | Limit |
|----------|-------|
| Home directory disk | **100 GB** |
| scc queue max duration | 10 days |
| long queue max duration | **120 days** |
| /work, /localscratch | No limit |

Quota check: `/software/bin/quota`

---

## General Rules

- Use resources carefully and sustainably
- Contact Stefan for any issues or questions: `Stefan.Gerlach@uni-konstanz.de`
- If unusual usage is detected, Stefan will contact you
- Notify Stefan to have your account deleted when you stop using the cluster
